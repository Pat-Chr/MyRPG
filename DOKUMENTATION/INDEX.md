## 🎯 Nutzungsempfehlungen

### Für Entwickler:
1. **Bevor du codest:** Öffne `DesignDocument.md` im Editor
2. **Bei Änderungen:** Dokumentiere in `DesignDocument.md` unter "Erweiterungsmöglichkeiten"
3. **AI-Assistenten verwenden:** Siehe [AI-Nutzung-Leitfaden.md](./AI-Nutzung-Leitfaden.md)

### Für AI-Assistenten (Copilot, etc.):
1. **Immer zuerst DesignDocument.md öffnen**
2. **Relevante Sektionen markieren** (z.B. "UpdateGame", "GameState")
3. **Befehle mit Kontext geben:** "gemäß DesignDocument.md implementieren"
4. **Generierten Code gegen Design prüfen**
